Real‑Time Vision Analyzer (OpenCV + YOLOv8)
A real‑time computer vision system built with Python, OpenCV, and YOLOv8 that detects objects live from your webcam.
This project demonstrates real‑time inference, object detection, and efficient model deployment — ideal for AI/ML portfolios.

🚀 Features
Live webcam object detection
YOLOv8 inference using CPU
Bounding boxes + labels + confidence scores
Works fully offline
Ultra‑lightweight and beginner‑friendly
📦 Tech Stack
Python
OpenCV
YOLOv8 (Ultralytics)
